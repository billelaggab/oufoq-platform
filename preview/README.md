# معاينة الواجهة (UI Preview)

ملف `index.html` معاينة بصرية تفاعلية لهوية تطبيق **منصة أفق**، مخصصة للعرض داخل
المتصفح لأن التطبيق نفسه مبني بـ Flutter ويستهدف نظام أندرويد حصراً (لا يوجد هدف web).

## التشغيل

```bash
cd oufoq_platform
python3 -m http.server 8080 --bind 0.0.0.0
```

ثم افتح: `http://localhost:8080/preview/`

## ما الذي تعكسه المعاينة بدقة؟

- **نفس خط Tajawal** بملفاته الخمسة المدمجة في `assets/fonts/Tajawal/` (عبر @font-face).
- **نفس لوحة الألوان** من `lib/core/theme/app_colors.dart` (الوضعان النهاري والليلي).
- **نفس النصوص العربية** المعرّفة في `lib/core/l10n/arb/app_ar.arb` (عناوين التبويبات،
  حالات الفراغ، الإعدادات، تصنيف "إعلان"…).
- **نفس قواعد الطباعة**: `letter-spacing: 0` وارتفاع سطر 1.35 للعناوين و1.55–1.7 للنصوص.
- بنية الشاشة الرئيسية الفعلية: شريط عاجل، بحث، خبر بارز، شريط أقسام، قائمة أخبار،
  موضع إعلان، وشريط تنقل سفلي بأربعة تبويبات قابلة للتبديل.

## حدود المعاينة

هذه ليست نسخة Flutter عاملة: لا تستدعي WordPress API ولا قاعدة SQLite ولا AdMob.
السلوك الكامل موجود في تطبيق أندرويد القابل للبناء:

```bash
flutter build apk --debug
# المخرَج: build/app/outputs/flutter-apk/app-debug.apk
```
